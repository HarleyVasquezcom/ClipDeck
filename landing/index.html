ClipDeck

Clip any page — title, URL, main text and main image — into a searchable deck of cards that stays in your browser. Tag them, find them, export them.

Download the extension (.zip)

One click, one card

The content script extracts the article text and the principal image with a local heuristic — the deck grows without any account or server.

article+hero

Search and tags

Every card accepts tags; the deck search filters by title, tag or text as you type.

research, demo

Export anywhere

Download the deck as Markdown or JSON and take it to any tool. Everything is exported from chrome.storage.local — nothing is sent anywhere.

.md / .json

Install (load unpacked)

  1. Download clipdeck.zip and unzip it.
  2. Open chrome://extensions, enable Developer mode.
  3. Click Load unpacked and select the folder.
  4. Open a page, press ClipDeck in the toolbar and hit clip this page.
